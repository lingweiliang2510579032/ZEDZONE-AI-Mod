[h1]AI伴侣（测试版v0.3）[/h1]
《隔离区（ZED ZONE）》的 AI 伙伴模组（MIT 开源），完整支持[b]游戏本体全部 10 种官方语言[/b]，提供 [b]API 直连大模型[/b] 与 [b]DSH 本地智能体[/b] 两种接入方式，并可在[b]聊天陪伴 / 接管雇佣 NPC / 联机玩家[/b]三种表现形式间随时切换。

[h2]一、安装前必看（重要）[/h2]
[olist]
[*][b]必须先安装前置加载器[/b]：请先订阅所需物品 [b]ZED ZONE Code Mod Loader（3834614258）[/b]，在其工坊文件夹中运行一次 [code]install.cmd[/code] 完成安装（安装过一次即可）。
[*]订阅本模组并在主菜单的模组列表中启用，重启游戏即可生效。
[*]支持语言：简体中文、English、Deutsch、Español、Français、日本語、한국어、Polski、Português、Русский，默认自动跟随游戏语言，也可在设置里手动切换。
[/olist]

[h2]二、怎么打开设置与聊天[/h2]
[list]
[*][b]打开配置界面[/b]：进入游戏按 [code]ESC[/code] → [b]游戏选项[/b] → 找到 [b]AI 伙伴[/b] → 点击 [b]打开 AI 伙伴设置[/b]，会弹出独立的 4 分页设置窗。
[*][b]单人与联机聊天[/b]：按 [b]Enter 键[/b]打开游戏左侧官方聊天框即可直接和 AI 对话或下达请求；所有回复都会控制在合适长度内并正确换行显示在左侧聊天框。
[/list]

[h2]三、两种接入模式[/h2]
[olist]
[*][b]API 模式（多数玩家推荐）[/b]：在设置第 3 页选协议（Chat Completions / Anthropic Messages / Responses / 本地 Ollama），填写 BaseUrl、模型名与 API Key（本机 Windows 加密保存，不存明文），点「测试连接」成功即可使用。
[*][b]DSH 模式（配合 DeepSeek Harness 使用）[/b]：在游戏设置第 1 页切换为 DSH 模式，并在 DSH 桌面端安装同版本 [code]zed-ai-dsh-plugin-v0.3.zip[/code] 插件（可从 GitHub Releases 下载），即可由本地智能体思考并保持同角色跨地图长期记忆。仅用 API 模式无需安装 DSH 插件。
[/olist]

[h2]四、三种表现形式与单联机适配[/h2]
[list]
[*][b]1. 聊天陪伴模式[/b]：在左侧官方聊天框自然聊天（内置防复读机制），会在掉血、饥渴、手电低电量、未加点数或遇敌时给出口语提醒。严格遵守不作弊规则：只读已解锁配方、身上物品与[b]同楼层视野内已打开检视过[/b]的箱子，绝不剧透未探索内容。所有背包整理、合成、丢弃等修改权限均[b]默认关闭[/b]，需在设置第 4 页手动授权；联机状态下只执行高亮指引、手电与只读制造规划。
[*][b]2. 接管雇佣 NPC 模式[/b]：仅在单人或联机房主且已雇佣队友时生效，严格按游戏官方队友指令范围控制：跟随、驻守、架枪警戒、开火/停火、远近战偏好、搜刮附近资源、拾取物品、使用手雷与治疗烟雾。不越权代办建造、合成或开车。
[*][b]3. 联机玩家模式[/b]：为 AI 生成独立联机角色卡作为正常玩家加入房间，协同战斗、搜刮与在房间聊天框发言。单人游玩时可开启「单机自动开启本地联机房」或在设置第 3 页一键开启本地房，让 AI 玩家直接进房陪玩。
[/list]
